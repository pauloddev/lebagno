# Le Bagno — site institucional

Site estático (HTML/CSS/JS), pronto para Vercel ou Netlify. Sem build: a raiz do repositório é publicada como está.

- `index.html`: home com intro do logo e as seções
- `catalogo.html`, `marcas.html`, `inspiracoes.html`: páginas complementares
- `js/config.js`: telefones, endereços, WhatsApp, Instagram e mensagens (edite aqui)
- `js/produtos.js`: produtos do catálogo (adicione e edite aqui)
- `css/style.css`: cores, fontes e espaçamentos centralizados no bloco `:root`

Desenvolvido por Logotop Design.
